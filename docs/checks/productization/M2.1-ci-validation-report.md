## 2. 阻塞证据

采集时间 2026-11-08T19:36:19+08:00，命令与原始输出：

```
$ git push origin main
fatal: unable to access 'https://github.com/LNiiuu/rds-mother-system/':
       schannel: server closed abruptly (missing close_notify)
rc=128

$ curl --noproxy '*' https://github.com          # 直连
curl: (28) Connection timed out after 15007 ms
http=000

$ curl https://github.com                        # 经本机代理
curl: (28) Operation timed out ... 0 bytes received
http=000

$ curl https://api.github.com/repos/LNiiuu/rds-mother-system   # 对照
http=200

$ git ls-remote origin                           # 显式代理
fatal: ... CONNECT tunnel failed, response 502
```

判读：

- `github.com:443` **直连超时、经代理 502**；`api.github.com` 200 —— 出口策略只放通了 API 域，未放通 git 传输域。
- 换 `http.sslBackend=openssl` 结果相同（`SSL_read: unexpected eof`），排除 TLS 后端问题。
- 关闭沙箱后直连仍超时（`Failed to connect to github.com:443 after 21102 ms`），排除沙箱单独限制。
- 无 `gh` CLI；`GH_TOKEN` / `GITHUB_TOKEN` 均未设置；读取系统凭据管理器属禁止行为，未尝试。
- WSL 被安全策略强制拦截（`PROGRAM BLOCKED BY SECURITY POLICY - wsl.exe`），无法借此获得 Linux 环境。

**判定：这是外部基础设施/网络策略阻塞，属于任务书 §9 允许记录为 BLOCKED 的情形。**
