## G. 未完成事项与限制

1. **CI 未运行**：未 push，无法触发；不得把本地结果写成 CI 通过。
2. **Linux / macOS 未跑 M9–M11**：M6 的 macOS 结论不覆盖本轮新增代码。
3. **真实模型 A/B 未做**：无 API、不购买服务；压缩效果只有确定性样本。
4. **语义摘要未实现**：不调用模型；「智能压缩」目前只是确定性压缩。
5. **摘要过期判断未实现**：只有哈希校验，没有源版本联动。
6. **无重试/超时/心跳**：任务只有 block/fail；没有自动重试与幂等控制。
7. **多 Agent 为模拟**：同进程顺序执行；`simulated=true`。
8. **无进程级隔离**：角色权限是 CLI 校验，不是沙箱。
9. **项目级 ACL 未细化**：仍由身份文件 `project_ids` 决定。
10. **`project use` 不自动生效**：只写指针，命令仍需 `--project`。
11. **`paths:assets` 在源码树出现 1 个 warn**：新文档含一处本机路径示例，属文档卫生问题。
