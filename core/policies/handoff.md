# 会话中断与交接规范

## 触发

- 上下文接近耗尽、会话将结束、任务跨会话、成员掉线、需要人工审批而暂停。

## 最小上下文包（恢复只需这些）

1. `project.yaml`（项目根）
2. 当前任务卡（含 inScope / 验收 / 证据要求）
3. 交接单（`core/templates/handoff.md`）
4. 最近一次证据索引
5. 当前 Git HEAD 与工作树状态

## 交接单必填

任务 ID、状态、已完成、未完成、关键决策、未决问题、证据路径、回滚点、下一步第一个动作。

## 恢复步骤

1. 读 `project.yaml` → 2. 读交接单 → 3. 校验 Git/文件状态与交接单一致 → 4. 读当前任务卡 → 5. 从"下一步第一个动作"继续。

## 禁止

- 依赖聊天历史作为唯一状态来源；
- 不写交接单就换会话；
- 交接单写"应该没问题"这类不可核结论。
