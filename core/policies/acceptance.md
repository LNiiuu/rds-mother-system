# 验收规范

## 质量门

| 门 | 判据 |
|---|---|
| G1 需求 | 目标、边界、验收标准可测 |
| G2 方案 | 有备选与回滚 |
| G3 实现 | 仅改 inScope；验证命令通过 |
| G4 审查 | 独立复跑通过；无阻断缺陷 |
| G5 验收 | 用户确认 |

## 结论

- 三态：**通过 / 有条件通过 / 不通过**；"有条件通过"仅限任务书记载的例外项，且须写明解除条件。
- 缺陷级：阻塞 / 高 / 中 / 低。阻塞未清不得通过。

## 证据

- 命名：`EV-YYYYMMDD-NNN-<说明>.log|md|json`
- 强度：E1 直接实测 / E2 配置或既往记录 / E3 单一来源 / E4 推断
- 每条结论必须带证据编号或标 E4；无证据的结论不得写"已验证"。
