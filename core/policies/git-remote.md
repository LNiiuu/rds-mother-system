# Git 与远程同步纪律

## 三层

1. 本地 Git 仓库（主）
2. GitHub Private（远程/异地）
3. 本地 ZIP（离线，仓库外，带 SHA-256）

## 纪律

1. 只同步母体系仓库；不同步任何业务仓库。
2. 不上传真实样本（APK/PCAP/二进制）；只上传索引、来源、SHA-256。
3. 不上传 `.env`、Token、密码、密钥、个人数据、缓存、日志。
4. 禁止 `--force` / `--force-with-lease`；禁止删远程分支/tag/历史。
5. 禁止改远程可见性与权限（单独审批）。
6. 首次 push 单独审批：敏感扫描 0 + 内容审查 + 目标核对 + `--dry-run`。
7. 自动同步默认关闭；开启需单独策略。
8. push 前守卫：分支正确、无敏感文件、无样本、目标 URL 正确、`fetch` 后非快进则停。
9. 每次同步记录：时间、方向、本地 HEAD、远程 SHA、文件数、结果、审批号。
10. 凭据只在本机配置，不入库、不写文档、不进日志与提示词。
