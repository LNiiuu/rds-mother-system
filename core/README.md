# core —— 母体系内核

| 子目录 | 作用 | 谁读 |
|---|---|---|
| `policies/` | 强制规则（权限、任务、验收、Git、交接、冲突） | 总控 + 全体 |
| `protocols/` | 数据契约（任务卡、证据） | 总控 + 实现 + 审查 |
| `roles/` | 角色卡与席位表 | 总控派单时 |
| `workflows/` | 端到端流程 | 总控 |
| `templates/` | 项目与交付模板 | 初始化时 |
| `bootstrap/` | 新项目加载流程 | 接入新项目时 |
| `scripts/` | 可执行脚本 | 初始化/维护 |

**加载原则**：新会话先读 `project.yaml`，再按需读本目录文件；不要一次把所有策略塞进上下文（见 `core/policies/handoff.md` 的"最小上下文包"）。
