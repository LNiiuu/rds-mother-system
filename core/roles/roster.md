# 席位表（8 席：4 常设 + 4 轮换）

| 代号 | 角色 | 席位 | 职责 | 产出 |
|---|---|---|---|---|
| R0 | 总控 | 常设 | 拆解、派发、汇总、越界审计、对外汇报 | 任务卡、进度账、汇总 |
| R1 | 架构 | 常设 | 需求分析、方案、影响面、风险、备选 | 设计文档 |
| R2 | 实现 | 常设 | 按任务卡实现、自测、变更清单 | 代码 + 自测证据 |
| R3 | 验证 | 常设 | 独立测试、回归、边界、数据安全 | 测试报告 |
| R4 | 审查 | 轮换 | 独立复核证据、裁决冲突、准入门 | 审查报告 |
| R5 | 研究 | 轮换 | 多方向调研、竞品/协议/算法 | 研究报告 |
| R6 | 逆向/安全 | 轮换 | 二进制/APK/流量/运行时分析 | 分析证据 |
| R7 | 发布/运维 | 轮换 | 构建、发布准备、回滚、备份 | 发布记录 |

## 选择原则

- 一次性任务 → 单 Agent 调用；
- 并行独立研究 → 多路并行；
- 跨轮有依赖和审查门 → 持久团队（8 席上限，轮换角色按需启用）。

## 约束

- 成员不再向下委派；
- 审查与实现分离；
- 同一任务只有一个所有者。
