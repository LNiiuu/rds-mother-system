# W-04 调用链与缺陷定位

- 目标：从症状或入口出发，沿调用关系收敛到可疑函数，给出可复核的根因假设。
- 输入：目标二进制/APK 或源码、症状描述、已知入口。
- 角色：R2 执行；R6 复核调用边；R0 汇总。
- 工具：REA `procedure_callees` / `procedure_callers` / `xrefs` / `get_call_graph`；源码场景用 grep 沿调用名检索。
- 步骤：
  1. 固定入口（main/entry/崩溃栈顶）。
  2. 逐层展开被调方，记录“调用方→被调方”边与 evidence_id。
  3. 标出外部 API 边界（系统调用、加密、文件/网络）。
  4. 给出 ≥2 个根因候选并标注证据强度（E1–E4）。
- 输出：`rea/evidence/EV-*-w04-*.md`，含调用链图（文本）、候选根因、置信度、未验证项。
- 失败分支：间接调用不可解析→记 unknown，不得臆测目标。
