# WF3 缺陷修复

## 流程

1. **缺陷单**（R3/用户）：编号、严重级、复现、期望、环境。
2. **根因**（R1）：≥2 个候选原因与排除依据；定位到文件/行。
3. **修复卡**（R0）：最小 inScope；验证命令；回归范围。
4. **先失败用例**（R2）：写出能复现的失败用例，确认失败。
5. **修复**（R2）：最小改动；用例转绿。
6. **验证**（R3）：独立复跑 + 回归 + 越界检查。
7. **审查**（R4）：证据链与根因一致性。
8. **收口**（R0）：缺陷单关闭；记录原因与影响。

## 禁令

- 禁止改测试迁就实现。
- 禁止顺手重构扩大范围。
- 2 轮未修复 → 升级用户并给替代方案。
