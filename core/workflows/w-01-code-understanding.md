# W-01 代码理解与依赖分析

- 目标：在不修改目标代码的前提下，建立源码结构图与模块依赖边，回答“谁依赖谁、入口在哪”。
- 输入：目标项目源码目录（只读）、项目配置（project.yaml / 包清单）。
- 角色：R2（代码理解）执行；R6（评审）抽查 3 条依赖边是否可复现。
- 工具：read / grep（源码）、项目自带测试与入口清单；不要求 REA。
- 步骤：
  1. 读入口配置（页面清单、启动脚本、包清单），统计入口数量。
  2. 扫描 import/require/using 关系，按“源文件:行号 → 目标”记录边。
  3. 聚合出核心层（被多处依赖的模块）与叶子层（无出边模块）。
  4. 标注未覆盖项（样式、资源、运行时注入）。
- 输出：`rea/evidence/EV-YYYYMMDD-NNN-w01-*.md`，含入口清单、依赖边表、核心/叶子分层、未覆盖项。
- 失败分支：目标不可读→记 BLOCKED；只有部分文件可读→记 PARTIAL 并列出未覆盖文件。
- 证据：每条依赖边必须带 `路径:行号`，不得只写模块名。
