# WF2 多方向研究

## 流程

1. **定义问题**（R0）：问题、边界、需要的方向、交付格式。
2. **选人**：按方向选 R5 或专项角色；并行 ≤6；每方向独立任务卡。
3. **并行研究**：每方向输出 5 段 + 证据（来源/E 级）。
4. **证据核查**（R4）：每方向抽 3 条证据回溯；不成立标"不采信"；证据不足整份降级为"草稿"。
5. **汇总**（R0）：合并同类项、保留分歧、标未验证。
6. **交付**：研究报告 + 证据索引 + 分歧清单。

## 规则

- 结论冲突不强行统一，交 R4 裁决并记录理由。
- 单一来源不算定论；推断必须标注。
- 研究不写业务代码；需要验证的假设单独立任务。
