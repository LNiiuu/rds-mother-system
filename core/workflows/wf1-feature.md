# WF1 需求交付

## 流程

1. **受理**（R0）：需求入卡；判断栈与影响面；确认走 WF1。
2. **方案**（R1）：目标/边界/影响面/风险/备选 → 设计文档；G2。
3. **拆解**（R0）：按可独立验收切片建任务卡；标依赖与 inScope。
4. **实现**（R2）：逐卡实现 + 自测；变更清单 + 证据。
5. **验证**（R3）：独立复跑；三态结论；缺陷单。
6. **审查**（R4）：证据链抽查；G4 准入。
7. **汇总**（R0）：8 节汇总；未完成与风险。
8. **验收**（用户）：G5；签收或打回。

## 门

G1 需求可测 → G2 方案有备选/回滚 → G3 仅改 inScope + 验证通过 → G4 独立审查 → G5 用户确认。

## 失败分支

- 验证不通过 → 缺陷单回 R2；同任务 ≤2 轮。
- 审查打回 → 补证据或修改；≤2 轮。
- 需求变更 → 回 G1，旧卡作废并记录。
