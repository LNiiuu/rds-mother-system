# 工作流

| 编号 | 名称 | 入口 | 出口 | 门 |
|---|---|---|---|---|
| WF1 | 需求交付 | 需求 | 验收单 | G1–G5 |
| WF2 | 多方向研究 | 研究问题 | 研究报告 + 证据核查 | G1/G4 |
| WF3 | 缺陷修复 | 缺陷单 | 修复 + 回归 | G3/G4 |
| WF4 | 方案评审 | 方案 | 评审矩阵 + 决策 | G2/G4 |

## 通用规则

- 每个任务一张卡；状态机见 `core/policies/task-management.md`。
- 审查（R4）与验证（R3）分离；实现不自我验收。
- 失败回退最多 2 轮，第 3 轮升级用户。
- 证据编号与强度见 `core/protocols/evidence.md`。

## 选择

- 需求明确、改动可控 → WF1
- 信息不足、多方向 → WF2
- 已有缺陷 → WF3
- 方案有争议/高风险 → WF4
