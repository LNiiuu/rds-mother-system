# 证据协议

## 编号

`EV-YYYYMMDD-NNN`，按生成顺序递增，不复用。

## 记录内容

1. 结论（一句话）
2. 命令/操作（可复跑）
3. 输出摘要（关键行，避免整段粘贴）
4. 环境（主机、版本、路径）
5. 时间戳
6. 证据强度 E1–E4
7. 关联任务 ID

## 强度

- **E1**：本次直接实测的输出（命令 + 结果）。
- **E2**：配置文件、既往报告、他人记录（需注明来源）。
- **E3**：单一来源、未交叉验证。
- **E4**：推断（必须显式标注"推断"）。

## 存放

- 母体系自身：`rea/evidence/` 或 `docs/acceptance/`
- 项目侧：项目 `evidence/`（不入母体系）
- 大文件不入库；只留哈希与来源。
