# W-05 PCAP / 流量分析

## 适用 / 前置
- 授权 pcap；REA pcap 可能被安全策略拦截。

## 输入
- pcap 路径、哈希、关注点（会话/字段/可疑流）。

## 步骤
1. 根因确认：规则/插件/匹配条件（E1）→ 2. 放行则 REA 实调；否则 tshark CLI 做允许范围验证 → 3. 结论与边界。

## 证据
- 根因报告、会话/字段/可疑流、结论、evidence_id。

## 失败分支
- 被拦截 → 记 **L2-blocked** + 解除条件；不得写 L2/L3；不得绕过策略。

## 不适用 / 禁令
- 不抓真实流量；不改安全策略（需 AUTH-04）。

## 复跑
- 同一 pcap 复跑，字段与结论一致。
