# W-01 代码库理解与依赖梳理

## 适用 / 前置
- 需要一个可读代码库；工具：静态分析（artifact/web/electron/dotnet）或 JS 应用图。

## 输入
- 代码路径、入口线索、目标问题。

## 步骤
1. 识别入口与模块图。2. 列关键调用与依赖。3. 标高风险点。

## 证据
- 入口清单、模块图、关键调用、样本/仓库哈希、evidence_id。

## 失败分支
- 工具不可用 → 记录不可用原因，改用文本检索；不得宣称已完成分析。

## 不适用 / 禁令
- 不分析未授权代码；不执行样本。

## 复跑
- 记录命令与版本，换时间复跑结果一致或差异有解释。
